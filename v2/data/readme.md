# 실험 데이터
본 연구에서는 실험 데이터로 [eICU Collaborative Research Database](https://eicu-crd.mit.edu/)를 사용하였다.
실제 실험에서는 여러 데이터 중 환자 데이터인 patient.csv, 진단 데이터인 diagnosis.csv를 하나의 데이터로 매핑하여 사용하였다.
용량 문제로 도메인 분리된 두 데이터셋을 업로드한다.
<br>
## hospital73.csv
Source dataset. Source Domain인 병원 ID 73의 병원 데이터이다. 
## hospital175.csv
Target dataset. Target Domain인 병원 ID 175의 병원 데이터이다.
